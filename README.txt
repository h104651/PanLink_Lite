PanLink Lite 百度下載管理器 2.0.0 — 完整修訂
Build: hardened-20261125（版本號維持 2.0.0）

安裝
1. 舊批次先按「停止新增」，讓已提交任務完成；不要按 PowerShell Ctrl+C。
2. 備份原有 Tampermonkey 腳本及 GM 儲存資料（如果可匯出）。
3. 開啟本包 panlink-lite-baidu-v2.0.0.txt，全選複製，完整取代原腳本，Ctrl+S。
4. 在百度網盤重新整理一次。確認標題「2.0.0 · 完整修訂」。
5. RPC 設定沿用 localhost:16800/jsonrpc、既有密碼、C:/AI-Shared/BaiduDownload。
6. 初始並行 3、單檔連線 4；自適應、網頁自動恢復、來源 MD5 嚴格校驗均預設 false。
7. 既有 v2 佇列可保留。首次執行會核對 OAuth 帳號；舊版未綁帳號的紀錄需人工確認。
8. 先做實機小批次驗收，不要把模擬測試視為實機驗收。若需要回退，請先停止新增並保留 .aria2、備份隊列。

新增與修復
- 官方 uinfo 帳號查核；佇列綁定 OAuth 帳號，頁面若提供 uk 也比對，授權改變會阻止新增。
- OAuth 新授權 state/到期檢查；現有 token 保留，失效時使用官方授權頁重新登入。
- GID、路徑及大小檢查；外部重複目標不自動接管；接管需要明確確認。
- 暫停不占管理器下載名額；個別取消、全暫停、停止新增分開處理。
- 下載中 RPC 短暫斷線，5 次指數退避；不把傳輸故障當成 GID 不存在。保留不明提交並禁止盲目重送。
- RPC 並行/速度設定保存在租約紀錄；恢復時比對現行值，避免覆蓋已辨識的外部設定改動。意外關頁後須重新啟動管理器才能恢復設定；不保證區分其他工具恰好寫入相同設定值。
- 自適應 3→4→5（依設定），飽和樣本至少 40 個及 120 秒，改善不足 10% 退回；不突破服務端限制。速度曲線為最近 100 個採樣，平均速度為採樣估計。
- 直鏈即時取得並保留簽章；已知到期的直鏈不提交，符合已知到期的 HTTP 410 或暫時傳輸錯誤有限次重取。403/429 一律暫停新增，必須檢查授權/服務端限制再人工恢復；不將 403 猜測為過期。
- 本機校驗報告匯出/匯入；可用來源提供的 MD5 比對，預設不強制（來源 MD5 語意須實機驗證）；SHA256 只作本地基準。校驗異常不刪除/覆蓋檔案，撤銷已完成紀錄，重試前需人工處理。
- 100 筆一頁任務顯示、篩選、速度圖、RPC 密碼/BDUSS 密碼欄位、RPC 僅本機、路徑安全檢查。

校驗（選配）
在管理器停止後點「導出校验清单」，將 JSON 與 Verify-BaiduDownloads.ps1 放到本地。PowerShell：
  .\Verify-BaiduDownloads.ps1 -Manifest .\baidu-download-manifest.json -Hash -Report .\baidu-verification.json
如已確認來源提供的 MD5 可與普通文件 MD5 比對，可加 -CompareSourceMd5。
然後回到管理器，按「導入校验报告」選擇報告。報告檔必須使用新名稱，不覆蓋既有檔案。
只會讀本機檔案並產生新報告，沒有網路請求或刪檔。請勿在下載同一批檔案時校驗。
